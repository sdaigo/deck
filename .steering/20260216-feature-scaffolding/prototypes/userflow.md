# ユーザーフロー: Scaffolding

## メインフロー

scaffolding フェーズでは機能的なユーザーフローは限定的。
初回アクセス時の表示と、エラー発生時の復旧フローを定義する。

```mermaid
graph TD
    A((アプリにアクセス)) --> B[初期画面]
    B --> C{正常に表示?}
    C -->|はい| D[アプリシェル表示]
    D --> E((次フェーズの機能を待つ))

    C -->|いいえ - ランタイムエラー| F[ErrorFallback 画面]
    F --> G{ユーザーの選択}
    G -->|再読み込み| A
    G -->|データをリセット| H((localStorage クリア))
    H --> A

    B --> I{Toast 通知?}
    I -->|ストレージ警告| J[Toast 表示]
    J --> K{ユーザーの対応}
    K -->|手動で閉じる| D
    K -->|5秒待つ| L((自動消去))
    L --> D
```

## 画面一覧

| # | 画面名 | 説明 | 状態 |
|---|--------|------|------|
| 1 | 初期画面（アプリシェル） | ヘッダー + 空のメインエリア | 正常時 |
| 2 | ErrorFallback | エラーメッセージ + 復旧ボタン | エラー時 |
| 3 | Toast 通知 | 画面右上のスタック通知 | 警告/エラー発生時 |

## 凡例

- 円: ユーザーアクション
- 矩形: 画面/UI 状態
- 菱形: 意思決定ポイント
