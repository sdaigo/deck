# ドキュメントレビュー

引数: `/review-docs [ドキュメントパス]`

1. ドキュメントの存在を確認
2. サブエージェント（general-purpose）を起動し、以下の観点でレビュー:
   - 完全性: 必要な項目が全て含まれているか
   - 具体性: 曖昧な表現がないか
   - 一貫性: 他のドキュメントと整合しているか
   - 測定可能性: 成功指標が測定可能か（PRDの場合）
3. レビュー結果の要点を抽出してユーザーに報告
