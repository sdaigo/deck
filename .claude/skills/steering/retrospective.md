# 振り返りモード

## 目的

実装完了後、tasklist.mdに振り返りを記録し、プロセス改善を docs/ に反映する。

## 手順

1. tasklist.mdを読み込む
2. 振り返り内容を作成:
   - 実装完了日
   - 計画と実績の差分（計画と異なった点）
   - 学んだこと（技術的な学び、プロセス上の改善点）
   - 次回への改善提案
3. Editツールでtasklist.mdの「実装後の振り返り」セクションを更新
4. プロセス改善の反映:
   - 「次回への改善提案」にプロセスやテンプレートの改善が含まれる場合、該当する `docs/` ファイルまたはスキルテンプレートへの更新を提案する
   - ユーザーの承認を得てから反映する
5. ユーザーに報告: 「振り返りをtasklist.mdに記録しました。内容を確認してください。」
6. ステアリングディレクトリのアーカイブ案内:
   - 「このステアリングディレクトリ（`.steering/[日付]-[機能名]/`）は役割を終えました。不要であれば削除またはアーカイブできます。」と案内する
